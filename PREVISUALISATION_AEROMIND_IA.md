# Aeromind.IA — Prévisualisation

Ouvrir [AeroMind dans la prévisualisation HTTPS](https://3000-izi1svvqnalklpw3p4bsi-41310bc4.us3.manus.computer/).

La prévisualisation est également disponible dans le panneau **Preview** de ce projet. Cette adresse est temporaire et dépend du serveur de cette session ; ce n’est pas une publication de production.

Le module s’ouvre sans données aérodynamiques de démonstration. Sélectionner **3D Model Importer**, puis importer votre propre fichier STL, OBJ ou 3MF pour inspecter sa géométrie avec WebGL 2. Les unités doivent être vérifiées manuellement. Aucun résultat CFD n’est créé sans solveur raccordé.

L’interface nécessite un navigateur compatible WebGL 2 et un pilote graphique l’autorisant. En cas de refus du contexte, un diagnostic et un bouton de nouvelle tentative sont affichés ; aucun faux rendu 3D ni résultat artificiel ne remplace le calcul indisponible.
