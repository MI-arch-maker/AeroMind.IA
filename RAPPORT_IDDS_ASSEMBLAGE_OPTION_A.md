# IDDS — sous-vue Assemblage séquencé (Option A)

L’atelier virtuel d’assemblage du Studio IDDS présente désormais une vue éclatée guidée par une séquence en cinq étapes : Structure, Propulsion, Voilure & interfaces, Charge utile, Contrôle final.

- Sélectionner une étape sélectionne le composant correspondant et bascule la scène en vue éclatée.
- Les prérequis et consignes de revue sont affichés dans l’inspecteur.
- L’avancement est marqué manuellement; il s’agit d’une revue utilisateur, non d’une certification technique.
- La recherche, l’arborescence des composants, l’orbite/zoom, l’éclatement, les transformations de matériels installés et la bibliothèque restent accessibles.
- Les calques peuvent être créés à partir du composant actif; l’affectation est conservée dans la configuration de projet.
- La bibliothèque reste disponible à la demande afin de conserver l’espace de l’atelier pour la séquence.

**Validation :** TypeScript et build réussis; tests : 41 fichiers, 195 tests réussis. La preview est statique et ne valide pas une API distante.
